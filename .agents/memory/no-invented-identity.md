---
name: No invented user identity
description: Keep dashboard greetings and profile labels grounded in supplied user data.
---

Do not invent a user's name, initials, role, or personal profile details in product copy when the source data does not provide them.

**Why:** Placeholder identity copy can look like an assertion about the real user and undermines trust in an otherwise data-grounded dashboard.

**How to apply:** Use neutral labels such as “Good morning” or “Relationship manager” until the user explicitly supplies a preferred name or profile.
